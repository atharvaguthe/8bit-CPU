# 8-bit CPU — VHDL

An educational 8-bit CPU designed from scratch using VHDL.

The project aims to explore digital logic design, computer architecture, instruction execution, and hardware simulation.

## Architecture

- Architecture: 8-bit
- Data width: 8 bits
- Instruction width: 16 bits
- General-purpose registers: 8
- Control unit: Multi-cycle FSM
- HDL: VHDL
